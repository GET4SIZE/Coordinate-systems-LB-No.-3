# Coordinate-systems-LB-No.-3
Розробка додатку для візуалізації вимірювань GPS

## Що включено в рішення

Цей додаток виконує всі вимоги лабораторної роботи:

**Підключення до WebSocket** емулятора GPS  
**Аналітичний метод** розрахунку позиції (пряме розв'язання системи рівнянь)  
**Чисельний метод** розрахунку позиції (мінімізація похибки через `numeric.js`)  
**Візуалізація** супутників та обох розрахованих позицій на графіку  
**API інтерфейс** для зміни параметрів емулятора  
**Зручний UI** з логуванням та статистикою  

## Як запустити

### Крок 1: Запуск емулятора GPS

Спочатку потрібно запустити Docker контейнер з емулятором:

```bash
# Завантажити образ
docker pull iperekrestov/university:gps-emulation-service

# Запустити контейнер
docker run --name gps-emulator -p 4001:4000 iperekrestov/university:gps-emulation-service
```

Емулятор тепер працює на `ws://localhost:4001`

### Крок 2: Відкрити веб-додаток

Просто відкрийте файл `gps-visualizer.html` у вашому браузері (Chrome, Firefox, Edge):

- Подвійний клік на файл, або
- Перетягніть файл у вікно браузера, або
- Правий клік → Відкрити за допомогою → Браузер

### Крок 3: Підключитися

1. Натисніть кнопку **"Підключитися"** в інтерфейсі
2. Дочекайтеся повідомлення про успішне підключення
3. Додаток автоматично почне отримувати дані та відображати їх на графіку

## Як користуватися додатком

### Візуалізація на графіку

- **Сині точки** - супутники GPS
- **Зелений трикутник** - позиція об'єкта (аналітичний метод)
- **Помаранчевий квадрат** - позиція об'єкта (чисельний метод)

### Зміна параметрів

У бічній панелі ви можете змінити:
- **Розмір зони емуляції** (км)
- **Частота повідомлень** (Hz)
- **Швидкість супутників** (км/год)
- **Швидкість об'єкта** (км/год)

Після зміни натисніть **"Оновити параметри"**

### Статистика

Додаток показує:
- Кількість активних супутників
- Кількість отриманих повідомлень
- **Похибку між методами** (різниця між аналітичним та чисельним розрахунками в метрах)

### Лог подій

Внизу відображається лог всіх подій:
- Зелений текст - успішні операції
- Червоний текст - помилки
- Звичайний текст - інформаційні повідомлення

## Технічні деталі

### Аналітичний метод

Розв'язує систему рівнянь кіл методом виключення:
1. Бере три супутники
2. Створює систему рівнянь на основі відстаней
3. Лінеаризує систему віднімаючи рівняння
4. Розв'язує систему 2x2 для знаходження (x, y)

### Чисельний метод

Використовує оптимізацію через бібліотеку `numeric.js`:
1. Визначає функцію похибки (сума квадратів різниць)
2. Бере початкове наближення (центр мас супутників)
3. Застосовує метод безумовної мінімізації (`uncmin`)
4. Знаходить точку з мінімальною похибкою

### Використані бібліотеки

- **Chart.js** - для інтерактивних графіків
- **numeric.js** - для чисельної оптимізації
- **Нативний WebSocket API** - для зв'язку з емулятором

## Можливі проблеми та рішення

### Не вдається підключитися

**Проблема:** "WebSocket connection failed"

**Рішення:**
1. Переконайтеся, що Docker контейнер запущений:
   ```bash
   docker ps | grep gps-emulator
   ```
2. Перевірте, що порт 4001 вільний:
   ```bash
   netstat -an | grep 4001
   ```
3. Спробуйте перезапустити контейнер:
   ```bash
   docker restart gps-emulator
   ```

### Не відображаються точки

**Проблема:** Графік порожній

**Рішення:**
- Дочекайтеся отримання мінімум 3 супутників (потрібно для трилатерації)
- Перевірте лог подій - там має бути інформація про отримані дані

### Великі похибки між методами

**Проблема:** Похибка >100 метрів

**Рішення:**
- Це нормально для симульованих даних з невеликими похибками
- Зменшіть швидкість об'єкта для більш стабільних вимірювань
